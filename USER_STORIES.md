# Alliora — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Chief strategy officer

- As a CSO, I want the partnership portfolio mapped to the eight forces, so that I see whether we are only buying UX while ignoring platform and SIT risk.
- As a CSO, I want a kill recommendation when a pilot fails materiality gates, so that we stop confusing motion with progress.

### Partnerships / corp-dev manager

- As a partnerships manager, I want force-tagged scorecards when comparing two lending fintechs, so that “better app” does not beat “better economics and liability terms.”
- As a partnerships manager, I want experience-ownership and liability fields mandatory before legal review, so that we do not discover gaps after launch.

### Business-line product owner

- As a product owner, I want profit-pool hypotheses attached to the pilot, so that I know if we are funding our own disintermediation.
- As a product owner, when a distributor partner starts steering customers away from our brand, I want a platform-risk alert, so that we renegotiate before the interface is lost.

### Risk / procurement / resilience

- As a third-party risk officer, I want SIT concentration dashboards across cloud, data, and model vendors, so that resilience is not partner-by-partner theatre.
- As a procurement lead, I want mutualise-vs-build comparisons for KYC and ops tools, so that we stop paying five times for the same commoditised cost.
- As a resilience officer, when a critical vendor’s exit plan is missing, I want new spend blocked, so that convenience cannot create systemic dependency.

### Portfolio administrator

- As a portfolio administrator, I want stage-gate evidence packs exportable for audit and the board, so that innovation governance is examinable.
- As an HR business partner, I want bionic-workforce role maps before automation scale, so that talent transition is funded beside the software.
- As legal counsel, when manufacturer/distributor liability is unsigned, I want the contract status to block go-live, so that experience ownership does not become orphaned accountability.
